# TallyMyMoney

A personal Telegram bot that reads Singapore bank transaction-alert emails, asks one question per transaction, and reports monthly.

**Status: strategy phase. Nothing is built, and nothing should be built until SPIKE-01 returns a verdict.**

## Scope — read this before suggesting anything

**Personal tool. One user. No scale intent.** No growth targets, no distribution, no monetisation, no second user — ever, under the current decision. That constraint is deliberate and it is what makes the project cheap, fast and free to run.

Don't propose marketing, multi-tenancy, or a public launch. If it comes up, the answer is no.

## The one thing that decides whether this exists

Whether Nat's banks actually send a parseable email for **every** transaction.

The ideation dump contains confident regex patterns for DBS, OCBC and Citibank. They were generated by a language model, not observed from real email, and they are not evidence of anything. If the banks only alert above a threshold, or push to their app instead of emailing, there is no input and no amount of good engineering fixes it.

So the build order is: **prove the input exists → build the pipe → build the interface.** Not database, then backend, then bot.

## About `ideation-archive/`

Thirty-one files from a DeepSeek session on 2026-08-16, originally named `deepseek_python_20260816_*.py` and similar. Renamed for legibility; **content is byte-for-byte unchanged and nothing was deleted.**

Treat it as raw material, not specification. Where it contradicts `docs/`, `docs/` wins. It describes: a Python/FastAPI/Render stack (superseded by TypeScript/Next.js/Vercel), multi-user tables with stored email credentials (superseded — single user), a Google Sheets archive (cut), and invented US personas on a Singapore-bank product (discarded).

Its genuinely useful parts are the Telegram message mockups, the interaction flows, and the shape of the reporting.

## Stack (proposed)

Next.js App Router on Vercel · Neon Postgres · Drizzle · grammY · Google Apps Script for mail forwarding. $0/month.
